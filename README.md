# AutoConnect — AI-Powered CRM Lifecycle Automation

## Project Overview
AutoConnect is an independent CRM engineering portfolio project for a fictional European vehicle marketplace. It demonstrates how customer data, SQL segmentation, marketing automation and AI-assisted workflows can improve customer engagement and reduce manual CRM operations.

This project uses synthetic data and is not affiliated with any real vehicle marketplace.

## Business Problem
A digital vehicle marketplace needs to identify inactive customers, deliver relevant lifecycle communications and reduce the technical effort required to prepare CRM campaigns.

## Proposed Solution
- Model customer profiles, saved searches, browsing events and marketing consent.
- Identify eligible audiences using SQL.
- Design and implement a saved-search re-engagement journey.
- Develop an n8n AI assistant to support campaign briefs, segmentation and content preparation.
- Evaluate campaign performance using simulated engagement data.

## Technology Stack
- SQL / SQLite — customer data modelling and segmentation
- Python — synthetic data generation and analysis
- Brevo — email marketing and customer journey automation
- n8n — AI-assisted campaign operations
- REST APIs / Postman — integrations and testing
- GitHub — version control and technical documentation
